# Counter App — React Beginner Project 01

A small React application for learning components, JSX, `useState`, event handlers, and CSS.

## Requirements
- Node.js (LTS recommended)
- npm
- VS Code

## Run locally
```bash
npm install
npm run dev
```
Open the local address printed by Vite (usually http://localhost:5173).

## Build for deployment
```bash
npm run build
npm run preview
```
Vite creates the production build in the `dist` folder.

## Deploy to Vercel
1. Push this project to GitHub.
2. Import the repository into Vercel.
3. Select **Vite** as the framework preset.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

## What this project demonstrates
- Functional React components and JSX
- `useState`
- Click event handlers (`onClick`)
- Updating state with the functional setter form
- Conditional rendering
- Responsive CSS
